Expand description

Registers a static subtype of parent with a runtime name and class initializer.

This can be used to register types based on the runtime environment, such as available devices and their capabilities. Each type shares the same Rust implementation but can have different class configuration without a separate ObjectSubclass implementation.

The subtype uses the parent’s class and instance layouts. The parent must be T or a subtype of T, and must not be final. Parents registered through GTypePlugin are not supported. Parents registered at runtime with this function are supported.

class_init may run later on another thread. The closure and its captures are kept for the lifetime of the type. The closure must not panic.

Panics if the parent does not meet these requirements, the name is already registered, or registration fails.
